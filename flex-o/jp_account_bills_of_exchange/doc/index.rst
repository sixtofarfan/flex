=========================
Account Bills of Exchange
=========================

This module provides functionallity to Odoo to exchange
invoices with bills of exchange. Manage the bills of exchange
and control due date.

Installation
============

To install this module, you need to:

Download the module and add it to your Odoo addons folder. Afterward, log on to
your Odoo server and go to the Apps menu. Trigger the debug mode and update the
list by clicking on the "Update Apps List" link. Now install the module by
clicking on the install button.

You also will need to download the following modules from OCA repository:

web_notify

Upgrade
============

To upgrade this module, you need to:

Download the module and add it to your Odoo addons folder. Restart the server
and log on to your Odoo server. Select the Apps menu and upgrade the module by
clicking on the upgrade button.

Configuration
=============

To start no additional configuration is needed to use this module. If you need
to adjust some setting please read the pdf manual included in this module.

Usage
=============

Exchange pending invoices for bills of exchange, and then manage them in the
module. Journal entries will be automatically created.
