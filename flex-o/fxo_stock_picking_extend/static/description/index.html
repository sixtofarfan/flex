Stock Picking Extend

Modulo de extensión para la impresión de guías y guías electrónicas

Modulo especial para agregar los datos del transportista y unificar las pestañas de Personalización Peruana y Transportista en la guía de salida.

Ademas de agregar la verificación si es una guía electrónica en la serie.

Seleccionar is EGuide en la secuencia

Esta configuración permitirá generar e imprimir la guía electrónica.

Selección de secuencia

Se selecciona el secuenciador que automaticamente mostrará el siguiente número.

Pestaña Personalización peruana

La pestaña personalización peruana aparecerá si el secuenciador tiene configurado el campo EGuide.

Pestaña Transportista

Los datos serán automaticamente ingresados luego de la selección del transportista, unidad y conductor.

Botón generar EGuide

Luego de validar el botón Generate E-Guide aparece para conectar con SUNAT y luego imprimir.
