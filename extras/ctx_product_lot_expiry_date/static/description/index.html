Product Lot/SN Manual Expiry Date

Overview

Odoo by default calculate the expiry dates depend on reception date, this module allows you to set manual expiry dates during the receiving process of PO shipment picking.

Features
Allows you to enter lot/SN expiry dates in receiving shipment picking form.
Ability to set only expiration date in receiving shipment picking form and leave other dates empty and it will be calculated using expiration date with days configured in product while receive PO incoming shipment.
Ability to leave all dates empty in receiving shipment picking form, so all dates will be calculated from reception date (Odoo Default)
Ability to use it with "Receipt" operation type with "use existing Lots/SNs" or "Create New lots/SNs"
Ability to see expiry dates as readonly in delivery outgoing picking and internal transfer picking.
It works with lot/SN product.
Works with\without Operation settings "Show Detailed Operations" and "Pre-fill Detailed Operations".
Easy to use without any configuration.
